## Commands
- Install rimraf (REQUIRED for generating the production build)
```console
npm install rimraf --save-dev
```
- Install all nodes
```console
npm install
```
- Start development server
```console
npm start
```
- Obtain the production build
```console
npm run build
```

- Start the rails server
```console
rails server
```
